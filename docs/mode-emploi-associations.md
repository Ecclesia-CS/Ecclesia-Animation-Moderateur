# Ecclesia — mode d'emploi pour les associations

Ecclesia met à votre disposition deux outils :

- **Débat simple** : une table de débat, avec un modérateur qui distribue la parole (file d'attente, coupe-file, temps de parole de chacun).
- **Sondage** : des affirmations sur lesquelles chacun vote « d'accord / pas d'accord / passe », à distance, avec les résultats et les camps d'opinion visibles en direct.

Vous pouvez avoir **3 séances en cours à la fois** (débats et sondages confondus). Une séance clôturée libère une place.

## 1. Se connecter

Allez sur **`https://ecclesia-cs.github.io/Ecclesia-Animation-Moderateur/#asso`**, puis saisissez le **nom de votre association** et le **mot de passe** qu'Ecclesia vous a communiqués.

Vous pouvez changer ce mot de passe à tout moment (lien « Mot de passe » en haut à droite). ⚠️ C'est aussi le mot de passe qui permet à vos modérateurs de prendre l'animation d'une table : pensez à leur communiquer le nouveau.

## 2. Organiser un débat

1. **« + Nouvelle séance »** → **Débat simple** → un titre → « Créer la séance ». Une table est créée automatiquement.
2. Ouvrez la séance, onglet **Préparation** : vous y trouvez le **lien** et le **QR code** à montrer aux participants.
3. Le moment venu, cliquez **« Passer en Débat → »** : la séance est ouverte, les participants peuvent entrer.
4. **Les participants** scannent le QR code, donnent leur prénom et nom, et arrivent à la table. Un **code de rappel** à 4 chiffres leur est affiché : il leur permet de revenir depuis un autre appareil.
5. **Le modérateur** fait de même, mais coche **« Je suis le modérateur »** et saisit le **mot de passe de l'association**. S'il est déjà entré comme participant : menu **Outils → Modérateur**, avec le même mot de passe.
6. À la fin, **« Passer en Clôturée → »**. Les participants voient « Séance terminée ». L'historique de la table (temps de parole) reste consultable dans l'onglet Tables.

## 3. Organiser un sondage

1. **« + Nouvelle séance »** → **Sondage** → un titre. Choisissez la modération des propositions :
   - **Fermée** : les affirmations proposées par les participants attendent votre validation ;
   - **Ouverte** : elles sont publiées immédiatement.
2. Onglet **En direct** → « + Ajouter des assertions » : saisissez vos affirmations (une par ligne, ou import CSV).
3. **« Passer en Vote → »**, puis partagez le lien ou le QR code (onglet Préparation). Chacun vote à son rythme, à distance.
4. Pendant le vote, l'onglet **En direct** montre la participation, les votes par affirmation, et le bouton **« Analyser les camps »** (il faut au moins quelques votants). Après chaque analyse, les camps reçoivent automatiquement un nom (5 nommages par jour ; au-delà, ils restent « Groupe 1, 2… » jusqu'au lendemain). Les participants voient eux aussi les résultats et les camps en direct.
5. **« Passer en Clôturée → »** met fin au vote. Les participants gardent l'accès à leurs résultats ; rien n'est rendu public.

## Bon à savoir

- Une séance jamais ouverte (« Phase 0 ») peut être supprimée (icône corbeille). Une fois ouverte, on la clôture.
- Si un participant a perdu son code de rappel, le modérateur peut lui en générer un nouveau (Outils Modo → Code participant).
- Une question, un problème : contactez Ecclesia.
