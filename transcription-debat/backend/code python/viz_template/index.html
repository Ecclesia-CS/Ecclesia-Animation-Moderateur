Où est allé le débat

Consensus et dissensus

Pour chaque affirmation : à droite ceux qui l'ont soutenue, à gauche ceux qui l'ont contestée, en pointillé ceux qui l'ont nuancée. Pas de pastille = ne s'est pas exprimé sur ce point, ce qui n'équivaut pas à être neutre. Cliquez une pastille pour aller au moment où la personne le dit.

Pour Contre Nuancé Chaque pastille porte le numéro de l'interlocuteur, dans sa couleur de la carte.

Accord Désaccord Concession (le point penche un instant vers l'autre)

Chaque inflexion d'une trajectoire correspond à une prise de parole scorée. Le point de la voix qui parle est mis en évidence. Pendant un long silence, la position reste figée : un déplacement n'a lieu qu'à une prise de parole réelle. Un cercle en pointillé signale une position globale estimée, sans prise de parole scorée individuellement.
